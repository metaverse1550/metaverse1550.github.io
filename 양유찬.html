끝말잇기 규칙 안내

1. 자유로운 단어 인정 (신조어/유행어 OK!) 일반 표준어뿐만 아니라 인터넷 용어, 드라마/영화 제목, 신조어, 유행어, 대중문화 단어도 모두 입력 가능합니다!
2. 두음법칙 자동 적용 'ㄹ'이나 'ㄴ'으로 시작하는 단어는 두음법칙에 따라 변환된 음절로도 입력 가능합니다.

예: '리' -> '니' 또는 '이' / '력' -> '역' / '녀' -> '여'

3. 점수 계산 방식 단어가 길수록 high score! 연속 성공시 콤보 보너스 점수가 누적됩니다.
4. 패스 & 시간 초과 (제시어 자동 변경) 제한 시간이 지나면 점수가 차감되고 새로운 제시어로 자동 변경되어 상대방에게 턴이 넘어갑니다.
